The Masking Lab Deck

Thirty cards across three suits — Past, Present, Future. Within each suit, a mix of metaphors (image-driven framings), questions (open prompts), and keywords (single concepts).

In the room: participants pull one Past, one Present, one Future card at the start of each parallel session — the cards seed the 4-quadrant grid. Metaphors point to paradoxes; questions surface challenges; keywords name opportunities.

For the artist: the dashed-border area on each card is the illustration slot. A placeholder pictogram sits there for now; an *image cue* line in the source markdown suggests a visual hook. See deck-cards.md for the working copy.
